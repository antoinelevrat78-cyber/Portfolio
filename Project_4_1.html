Adaptive 2D Delaunay Meshing & Image Compression

Project Overview

Project

Academic Project (Scientific Computing - MS14)
March - April 2026

Objective

Develop high-performance mesh connectivity data structures and a 2D Delaunay triangulation kernel from scratch, then apply adaptive meshing to compress grayscale images while preserving high visual fidelity in high-contrast regions.

Method

  • Implemented geometric mesh quality metrics (Q1 and Q2) and replaced a naive O(N²) neighbor-search algorithm with a custom hash table, reducing connectivity and boundary-edge detection complexity to quasi-linear O(N).
  • Benchmarked hashing key strategies (i+j, min(i,j), and i+j × 1000) across complex aerospace geometries (naca, ls89, hlcrm, up to 355,000 triangles), minimizing average hash collisions to approximately 1.94.
  • Built a 2D Delaunay insertion kernel using cavity computation (Bowyer-Watson) and signed-area point localization, improving triangle regularity (Q1 < 3) and runtime (approximately 2 s vs. 11 s for 3,000 points) over edge flipping.
  • Applied the kernel to grayscale image compression using barycentric interpolation and an iterative PSNR error-driven refinement loop to densify the mesh around sharp features.

Tools & Software

C, VIZIR4, Computational Geometry, Hash Tables, Delaunay Triangulation

Results

  • Achieved approximately 28 dB PSNR with adaptive meshing using 1,000 points, outperforming random Delaunay insertion with 5,000 points while preserving details such as eyes, mouth, and hands.
